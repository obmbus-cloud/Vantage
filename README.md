# VANTAGE — منصة فانتج للاستشارات

تطبيق داخلي لفريق مكتب فانتج للاستشارات: استقبال بيانات العملاء، تشخيصهم عبر محركات مالية/تشغيلية/تجارية/رقمية وقطاعية، وتوليد تقارير توصيات معتمدة قابلة للتصدير.

مبني بـ React + Vite، وقاعدة بيانات Supabase (PostgreSQL + Auth) مشتركة بين كل مستشاري الفريق.

---

## التشغيل محليًا (على جهازك)

يتطلب [Node.js](https://nodejs.org) (نسخة 18 أو أحدث).

```bash
npm install
npm run dev
```

سيفتح التطبيق على `http://localhost:5173`. القيم الافتراضية لقاعدة البيانات تعمل مباشرة بدون أي إعداد إضافي — ملف `.env.example` اختياري فقط إن أردتم قاعدة بيانات مختلفة لاحقًا (انسخوه إلى `.env`).

---

## النشر (Deployment)

أسهل طريقة: **Vercel** (مجاني للمشاريع الصغيرة).

1. ارفعوا هذا المجلد كمستودع على GitHub (خاص/Private، حتى لا يظهر الكود للعامة):
   ```bash
   git init
   git add .
   git commit -m "Initial commit — Vantage consulting app"
   git branch -M main
   git remote add origin <رابط المستودع الذي تنشئونه على GitHub>
   git push -u origin main
   ```
2. من [vercel.com](https://vercel.com)، سجّلوا الدخول بحساب GitHub، ثم "Add New Project" واختاروا هذا المستودع.
3. Vercel يكتشف أنه مشروع Vite تلقائيًا — لا حاجة لأي إعداد يدوي. اضغطوا Deploy.
4. بعد دقيقة تقريبًا، يصبح التطبيق متاحًا على رابط دائم (مثل `vantage-consulting.vercel.app`)، ويمكن ربطه لاحقًا بنطاق خاص بالمكتب (مثل `app.vantage.sa`) من إعدادات Vercel.

نفس الخطوات تقريبًا تنطبق على [Netlify](https://netlify.com) كبديل.

**بعد كل تعديل تدفعونه (`git push`) لاحقًا، ينشر تلقائيًا خلال دقيقة — بدون أي خطوة يدوية إضافية.**

## كيف تستمرون بالتطوير عليه

- **للتعديلات البرمجية:** استخدموا [Claude Code](https://claude.com/claude-code) مربوطًا بنفس مستودع GitHub — تطلبون أي تعديل بالعربية أو الإنجليزية ("أضف تصدير Excel للحالات"، "غيّر شعار المكتب")، فيعدّل الكود ويعمل commit مباشرة، ثم ينشر تلقائيًا عند الدفع.
- **لإدارة قاعدة البيانات** (أعمدة جديدة، تقارير SQL، مستخدمين): من [supabase.com/dashboard](https://supabase.com/dashboard) مباشرة، أو عبر Claude متصلاً بـ Supabase MCP.
- هذا الملف نفسه (`README.md`) مرجع دائم لأي مطوّر أو مستشار تقني ينضم للمشروع لاحقًا.

## ملاحظات أمنية مهمة

- **المفتاح العلني (`VITE_SUPABASE_ANON_KEY`) ليس سرًا** — من الطبيعي والمقصود أن يكون مرئيًا في كود المتصفح. الحماية الفعلية تأتي من سياسات **Row Level Security** المفعّلة على قاعدة البيانات (لا قراءة ولا كتابة بدون تسجيل دخول صالح).
- **لا تُدرجوا أبدًا** أي "Service Role Key" أو مفتاح إداري في هذا الكود — هذا النوع من المفاتيح يمنح صلاحيات كاملة متجاوزة لـ RLS ويجب أن يبقى على الخادم فقط، ولسنا بحاجته في هذا التطبيق أصلاً.
- **التسجيل مفتوح حاليًا** — أي شخص يعرف رابط التطبيق يمكنه إنشاء حساب مستشار جديد. لمكتب حقيقي يُفضَّل تقييد هذا لاحقًا (تسجيل بدعوة فقط)، ويمكن طلب هذا التعديل عبر Claude Code متى ما احتجتموه.
- يُنصح بتفعيل "Confirm email" و"Leaked password protection" من إعدادات Supabase (Authentication → Settings) لتقليل مخاطر الحسابات الوهمية وكلمات المرور المسرَّبة.
- راجعوا تبويب **Security Advisors** في لوحة Supabase بشكل دوري — يكتشف تلقائيًا أي إعداد أمني ضعيف في قاعدة البيانات.
